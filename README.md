# Pad Boy
A simple macropad consists of 5 switches, a rotary encoder, custom pcp, and a case

## Dimensions 

PCP dimensions: 60.5 mm * 62.5 mm.
Case dimensions: 80.9 mm * 82.9 mm.

## BOM

- 5x Cherry MX Kew Switches
- 1x Rotary Encoder Witch Switch
- Seeduino XIAO RP2040
- 3D Printing
- PCP Manifacture
